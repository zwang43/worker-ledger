## 🛠️ 使用方法

### 1. 选择版本
```bash
# 基础版本（适合简单使用）
open worker_ledger_local.html

# 增强版本（推荐，功能完整）
open worker_ledger_local_enhanced.html
```

### 2. AI记账设置
增强版本支持AI记账，需要：
1. **启动oMLX服务**
2. **启动oMLX桥接服务**
3. 支持自然语言描述，如：
   - "今天午餐花了35元"
   - "下班打车花了28元"
   - "买书花了129元"

### 3. 启动oMLX服务
```bash
# 自动安装（首次使用）
./setup-omlx.sh

# 手动启动
./start-omlx.sh

# 检查服务状态
./check-omlx.sh

# 停止服务
./stop-omlx.sh
```

### 4. 数据管理
```bash
# 导出数据
在工具箱页面点击"导出数据"

# 导入数据
在工具箱页面点击"导入数据"，选择JSON文件

# 备份数据
在工具箱页面点击"备份数据"
```

### 5. 主题切换
- 点击右上角🌙按钮切换深色/浅色主题
- 主题设置会自动保存

## 🔒 数据安全

### 本地存储
- 所有数据存储在浏览器 `localStorage` 中
- 不上传到任何云端服务器
- 数据仅保存在当前浏览器中

### 数据备份
- 支持手动导出JSON格式数据
- 支持浏览器本地存储备份
- 建议定期导出数据备份

### 隐私保护
- 无需注册登录
- 无需网络连接
- 数据完全本地化处理

## ⚠️ 注意事项

### 数据限制
- `localStorage` 通常限制为 5-10MB
- 大量数据可能影响性能
- 建议定期清理旧数据

### 浏览器隐私模式
- 隐私模式下数据可能不会保存
- 建议使用正常浏览模式

### 数据丢失风险
- 清除浏览器数据会导致记账数据丢失
- 建议定期导出备份
- 更换浏览器前请导出数据

### oMLX服务要求
- 需要Apple Silicon Mac (M系列芯片)
- Python 3.8+
- 可用的磁盘空间用于模型下载
- 网络连接用于首次模型下载

## 📞 技术支持

### 常见问题
1. **数据丢失**：检查浏览器存储权限，尝试恢复备份
2. **AI不工作**：
   - 确保oMLX服务正在运行: `omlx serve --host 127.0.0.1 --port 8080`
   - 确保桥接服务正在运行: `python omlx-bridge.py`
   - 检查端口是否被占用
3. **界面异常**：刷新页面，清除浏览器缓存
4. **模型下载失败**：检查网络连接，确保有足够的磁盘空间
