# 月度账单报告功能说明

## 功能概述

月度账单报告功能是记账工作台的自动化功能，可以每月自动生成详细的财务分析报告，帮助您更好地了解和管理个人财务状况。

## 主要功能

### 1. 自动生成报告
- **定时生成**：每月1日上午9点自动生成上月账单报告
- **智能检测**：避免重复生成已存在的报告
- **自动保存**：生成的报告自动保存到本地存储

### 2. 手动生成报告
- **随时生成**：可以手动生成指定月份的报告
- **灵活选择**：支持选择任意年份和月份
- **即时预览**：生成后立即查看报告内容

### 3. 报告内容
- **基本信息**：报告月份、生成时间、统计周期
- **收支统计**：总收入、固定支出、弹性支出、结余、储蓄率
- **支出明细**：按日期分类的所有交易记录
- **分类统计**：按支出类别汇总的统计信息
- **月度分析**：日均支出、储蓄率、收支状况分析
- **改进建议**：基于财务数据的个性化建议

### 4. 历史管理
- **历史查看**：查看所有历史生成的报告
- **下载功能**：支持将报告下载为Markdown文件
- **自动清理**：自动清理超过保留期限的旧报告

### 5. 配置管理
- **时间设置**：自定义自动生成的时间和日期
- **通知设置**：配置生成完成后的通知提醒
- **存储设置**：设置保留报告的月份数量
- **格式设置**：选择报告的输出格式

## 使用方法

### 1. 配置功能
1. 点击导航栏中的"报告配置"按钮
2. 设置自动生成的时间和日期
3. 选择是否启用通知提醒
4. 设置保留报告的月份数量
5. 点击"保存配置"完成设置

### 2. 手动生成报告
1. 点击导航栏中的"生成月度报告"按钮
2. 选择要生成报告的年份和月份
3. 点击"生成报告"按钮
4. 等待报告生成完成
5. 查看生成的报告内容

### 3. 查看历史报告
1. 点击导航栏中的"历史报告"按钮
2. 查看所有已生成的报告列表
3. 点击"查看"按钮查看报告详情
4. 点击"下载"按钮下载报告文件

### 4. 自动生成
系统会根据您设置的配置，在指定的时间自动生成报告。生成完成后，如果启用了通知功能，系统会发送通知提醒您查看报告。

## 技术特性

### 数据存储
- 使用localStorage本地存储
- 支持数据导入导出
- 数据加密保护

### 定时任务
- 基于JavaScript的定时器实现
- 智能调度下次生成时间
- 避免重复执行

### 通知功能
- 支持浏览器通知
- 可配置通知开关
- 优雅的通知提示

### 响应式设计
- 适配桌面和移动设备
- 优化的用户界面
- 流畅的交互体验

## 注意事项

1. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
2. **权限设置**：需要启用浏览器通知权限才能接收通知
3. **数据安全**：所有数据都存储在本地，不会上传到服务器
4. **性能优化**：大量数据时可能需要较长时间生成报告

## 故障排除

### 常见问题

**Q: 报告生成失败怎么办？**
A: 检查控制台错误信息，确保数据格式正确，重试生成。

**Q: 无法接收通知？**
A: 检查浏览器通知权限设置，确保已启用通知权限。

**Q: 历史报告丢失？**
A: 检查浏览器存储空间，清理缓存可能导致数据丢失。

**Q: 报告内容不完整？**
A: 确保当月有足够的交易记录，数据完整性影响报告生成。
